About This Project

This application was developed as part of the Summer PEP curriculum to demonstrate an automated end-to-end DevOps workflow.

CI/CD Pipeline Workflow

  1. Local Code Commit: Developer pushes code changes to GitHub repository.
  2. Automated Testing: GitHub Actions runs validation tests.
  3. Docker Image Build: Docker image is built and pushed to DockerHub.
  4. Automatic Deployment: Render pulls the updated image from DockerHub and deploys it live.
