About This Project

This interactive Tic-Tac-Toe web application demonstrates an end-to-end automated DevOps CI/CD pipeline.

Automated DevOps Architecture

  1. Local Code Push: Changes committed and pushed to GitHub main branch.
  2. Automated Testing (Job 1): GitHub Actions tests Flask app initialization and routes.
  3. Docker Build & Push (Job 2): Docker image is built and pushed to DockerHub (saisahas1/summer_pep_project:latest).
  4. Render Deployment (Job 3): Render receives deploy hook notification and deploys the updated Docker container automatically.
